What this prototype proves

Turn and direction remain compact in the top HUD. A slow low-opacity sweep now follows clockwise or counter-clockwise play across the background; Reduced Motion freezes it into a static trace.

Felt, Aurora, and Contours are built-in offline surfaces. Each uses a stronger element field plus the Lava/Sky/Grass/Sun pattern so the active colour reads without relying on colour alone.

Motion is explanatory only. Reduced Motion removes travel and pulse while keeping signed deltas, target outlines, symbols, text, and final values.

Card faces, backs, hero marks, type, colour treatment, and asset art are locked. The neutral cards only reserve layout space and demonstrate opposite-corner readability.

This file is a review surface, not a rules simulator and not production code.
